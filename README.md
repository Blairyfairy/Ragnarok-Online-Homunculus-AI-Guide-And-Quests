# Homunculus AI Midrate Guide & Philosopher’s Stone Alchemy Pack

**Full GitHub-ready repository** for Ragnarok Online private servers (mid-rate focus)  
with strong **Fullmetal Alchemist** thematic overlap.

This pack covers:

- Complete documentation of **Homunculus AI** (`/hoai`, AzzyAI, MirAI, alternatives)
- All important commands, configuration options, and packages
- Mid-rate specific AI adjustments
- Expanded **Creator → Genetic** progression with multi-area **Philosopher’s Stone Super Quest**
- Fusion NPCs inspired by FMA alchemy (human transmutation themes kept tasteful & game-friendly)
- **Stone of the Sage / Philosopher’s Stone** as rare, hard-to-obtain end-game alchemy catalysts
- Bonus NPCs for Acid Bottles, Immortal Hearts, and advanced alchemical ingredients
- Trainer NPCs that give best Genetic builds + card recommendations
- Common **Lua script errors** with Homunculus AI and how to fix them

## Fullmetal Alchemist / Alchemy Theme Integration

| FMA / Alchemy Concept          | In-Game Implementation                                      |
|--------------------------------|-------------------------------------------------------------|
| Philosopher’s Stone            | Ultra-rare catalyst item – hardest material in the pack     |
| Stone of the Sage              | Alternative / precursor item, still very rare               |
| Homunculus                     | Actual Homunculus system + AI                               |
| Human Transmutation            | High-cost fusion NPCs that require Philosopher’s Stone      |
| Equivalent Exchange            | Strict material + zeny costs on all advanced crafts         |
| Gate of Truth / Alchemy Circles| Visual / lore flavor in NPC dialogue                        |
| Alchemist Brotherhood          | Multi-area Super Quest across alchemy cities                |

The Philosopher’s Stone and Stone of the Sage are intentionally **hard** to obtain so they feel legendary.
